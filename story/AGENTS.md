# Story artifact rules

Files in this directory are authored outputs or references. They are not automatically playable and are never a substitute for a validated setting brief.

- `le-carnet-bleu.md` is an exploratory Maison Bleue novella, not canonical game input.
- New playable work belongs under `runs/<cute-run-name>/` with `setting.json` as its source of physical truth.
- Draft the structured `story.json` before expanding prose. The host guide and dossiers are projections of that story, not independent versions of events.
- If prose, clues, or stage directions contradict `setting.json`, the setting wins and the storyline must be revised.
